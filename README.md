# XHang IP Create Skill

为内容创作者设计可复用的个人 IP、虚拟主播或品牌吉祥物资产包。这个 Skill 的目标不是生成一张一次性头像，而是先锁定角色的一致性规则，再交付可用于长期视频生产的角色资产规范。

## 适用场景

- 为 AI 工具、职场成长、知识教育、生活方式或产品导览内容打造常驻角色
- 从人物参考图或文字设定出发，建立可持续复用的视觉锚点
- 规划角色的表情、口型、动作帧及有限动画边界
- 为插画资产、矢量绑定或 2D/3D 混合制作建立清晰交接规范

不适用于一次性的头像、Logo、海报插图，或只讨论命名与定位的需求。

## 工作方式

1. 用渐进式提问明确角色叙事职责、识别锚点、受众感受和表演需求。
2. 在批量制作前锁定视觉风格与生产模型。
3. 根据选择的模型给出可执行的资产包要求；高保真插画路线使用完整动作帧承载大幅动作，避免把细节插画误当成可任意骨骼变形的 SVG。
4. 交付前检查透明通道、一致性、清单路径与动画边界，避免过度承诺。

## 三种生产模型

| 模型 | 适合 | 取舍 |
| --- | --- | --- |
| 全插画 + 有限动作 | 高质感角色、品牌气质、知识讲解 | 大动作需要完整插画动作帧 |
| 优先绑定的分层矢量 | 高频姿态变体、低成本扩展 | 需要投入完整矢量系统，视觉通常更扁平 |
| 3D/2D 混合 | 转向、走路和更丰富的表演 | 制作与连续性成本更高 |

## 使用

将此目录放入 Codex 的 Skills 目录后，可以直接说：

```text
使用 $xhang-ip-create-skill 引导我创建个人角色资产包。
```

Skill 会先协助确定路线：

- 有参考图时，区分身份、风格、姿势和辅助素材的作用；
- 从零开始时，先确定内容赛道与观众感受；
- 在生成前展示并等待确认“风格锁定卡”。

完整行为规则见 [SKILL.md](SKILL.md)。高保真插画资产包的文件结构、清单和动画边界见 [资产包契约](references/asset-pack-contract.md)。
